# 무료 브라우저 검수

실제 브라우저에서 확인할 항목이다. 아래 예제는 게임 디자이너가 편집해 볼 수 있는 합성 프로젝트다. 평소 프로젝트를 저장한 프로필은 그대로 두고 **새 시크릿 창이나 폐기용 프로필**을 사용한다.

1. 저장소 루트에서 `$env:WORLDWEAVER_PROVIDER='mock'`을 설정하고 `.\scripts\start-dev.ps1`을 실행한다. 처음 설치할 때는 먼저 `.\scripts\setup.ps1`을 실행한다. 시크릿 창에서 `http://127.0.0.1:5173`을 연다. 아래 과정은 모델 생성 버튼을 사용할 필요가 없다.
2. **프로젝트 → Salt Census → 작업용 사본 만들기**를 누른다. **프로젝트 관리 → 프로젝트 백업 다운로드**로 이 사본의 JSON을 받는다. 원본 예제를 다시 열면 별도 프로젝트가 만들어진다.
3. **소재 → 아이디어 붙여넣기**에 여러 줄 원문을 입력한다. **규칙으로 정리** 후 일부 항목만 선택하고 인용을 펼친다. 언어를 바꾸고 프로젝트 목록을 다녀와 원문·제안 선택을 확인한다. 채택 전후를 비교할 때는 이 사본만 사용한다.
4. **스토리 후보**의 비교 기준을 결말로 바꾸고, 후보 하나의 본문과 고정 설정을 확인한다. **스토리 설계**에서는 진행과 결말 링크로 이동해 본다.
5. **시나리오 설계 → 시나리오 검증** 후 **The restored roll**을 선택한다. 상세 편집에서 검증이 돌려준 경로와 강조된 장면을 비교한다. **The sealed register**로 바꾼다. 개요 목록, 키보드 미니맵, 선택 항목 맞춤, 상세 편집 접기와 수동 배치 미리보기도 확인한다.
6. **세계 지도**에서 전체 범위와 장소 확대, 지하 장소의 상위 장소, 도로·교량 레이어, 지역·영토 레이어를 살핀다. 색인에서 장소를 선택하고 연결된 장면으로 갔다 돌아온다. SVG를 내려받아 실제 경로·이름·축척·범례를 대조한다.
7. **세계관 사전**에서 인물·세력·장소를 검색한다. 선택한 기록의 이웃, 사용 장면, 연결된 원천 기록을 연다. **검증 에이전트 → 빠른 검사 실행** 후 과거 이력과 현재 결과, 도구 실행, 소견의 근거를 확인한다.
8. **수정안 비교**를 보려면 배포용 예제 JSON에서 별도 파일을 만든다. 아래 명령은 저장소 루트에서 실행하며 출력 파일을 새 이름으로 만든다. **프로젝트 → 프로젝트 JSON 가져오기**로 이 파일을 가져온다. 빠른 검사에서 경로 거리 소견을 열고 **수정안 준비 → 분리된 사본에서 시뮬레이션**을 누른다. 수정 전후 거리와 의존성을 확인한 후 거절하거나 사본에만 적용·재검증한다.

   ```powershell
   .\.venv\Scripts\python.exe -c "import json,pathlib,tempfile; p=json.loads(pathlib.Path('frontend/public/examples/salt-census.json').read_text(encoding='utf8')); p['world']['routes'][0]['distanceKm']+=20; f=tempfile.NamedTemporaryFile(mode='w',encoding='utf8',suffix='.json',prefix='salt-route-review-',delete=False); json.dump(p,f,ensure_ascii=False); f.close(); print(f.name)"
   ```

9. **운영 및 설정 → 보관된 활동**에서 실제·모의 요청과 로컬 정리를 구분한다. **서비스 상태 확인** 전후의 결과·시각을 확인한다. 사용자 원문, 전체 서버 이용량, 배포 버전은 이력에서 추정하지 않는다.
10. 처음 만든 작업용 사본으로 돌아가 소재 하나를 저장하고 **프로젝트 → 프로젝트 JSON 가져오기**에서 2단계의 백업을 연다. 현재본과 백업의 차이를 확인하고 한 번 취소한다. 다시 비교한 상태에서 **같은 시크릿 프로필의 두 번째 탭**으로 동일 사본을 열어 편집·저장한다. 첫 탭의 복원 거절 → 최신 저장본과 다시 비교 → 명시적 복원 → 직전본 다운로드 순서로 확인한다. 새로고침 후 사본과 직전본을 확인한다. 종료 시 서버 터미널에서 `Ctrl+C`를 누른다.

## 화면 기록

1440×900에서 다음 열한 화면을 캡처하고 1280×720, 1920×1080과 960×720에서도 도구가 닿는지 확인한다. 실제 캡처는 **대기 중**이다.

| 캡처할 화면 | 볼 항목 |
|---|---|
| 01 프로젝트 | 첫 방문 예제 지도, 재방문 내 프로젝트 우선, 실제 지형 미리보기, 단계·수량, 가져오기 |
| 02 소재 | 원문과 검토안, 무료 정리와 AI 행동 구분 |
| 03 스토리 후보 | 같은 항목 가로 비교, 긴 한글, 본문 읽기 |
| 04 시나리오 편집 | 장·퀘스트 탐색, 겹치는 선 이름, 편집기 포커스 |
| 05 결말 경로 | 선택한 결말, 근거 범위, 강조 경로 |
| 06 지도 전체 | 해안·음영·레이어·나침반·축척 |
| 07 지도 상세 | 필수 장소 표지, 길·교량·지하 위치, 장면 왕복 |
| 08 세계관 사전 | 관계 목록과 그래프, 동명이인 구별 |
| 09 검증과 수리 | 근거와 대상 이름, 전후 값과 승인 영향 |
| 10 운영 | 출처별 최신 이력, 실제 요청과 로컬 처리 |
| 11 백업 복원 | 제목·항목 변경, 취소와 오래된 미리보기 거절 |

Tab·Shift+Tab으로 이동해 언어와 작업 공간을 바꾸고 현재 선택·초안·지도 위치가 유지되는지 확인한다. 작은 창의 탐색 메뉴와 세로로 접힌 비교 화면에서 버튼 잘림, 페이지 전체의 가로 스크롤, 한국어 글자 겹침, 색만으로 구별되는 상태를 기록한다. 자동 검사와 별도로 캡처 파일, 해상도, 브라우저·배율을 검수 결과에 남긴다.

### 5E.1 우선 검수

- 같은 격리 프로필에서 빈 목록을 확인하고 예제 사본을 열었다가 목록으로 돌아온다. 제목·마지막 저장·단계·열기 버튼이 먼저 보이고 예제가 한 줄로 줄어드는지 확인한다. 예제 기본본에서 시나리오 장소 1, 세계관 장소 7, 지도 배치 장소 7을 대조한다.
- 1920×1080, 1440×900, 1280×720, 960×720에서 목록·언어·백업 메뉴에 키보드로 접근한다. 960px에서 접힌 탐색을 열고 한글 제목, 버튼, 줄바꿈과 본문 가로 넘침을 확인한다. 위 표의 나머지 화면에서도 긴 한글, 작업 영역 폭과 스크롤을 기록한다.
- 실제 **잊혀진 달** 확인은 소유자가 평소 사용하던 동일 주소와 프로필에서 목록과 세계 지도의 저장본·작업본 표시만 읽는다. 창작 데이터와 저장 상태를 확인하는 데 복원·생성·채택은 필요하지 않다. 복원 비교 등 쓰기 검수는 격리 예제 사본에서만 진행한다.
