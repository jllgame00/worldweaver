# Phase 5E · 작업 공간 개편 결과

## 5E.1 최종 다듬기

**PARTIAL · 저장본 요약과 한글 조판 구현, 네이티브 시각 검수 대기.** 브랜치와 HEAD는 5E 시작점과 같다. 소유자가 실제로 본 화면은 변경 전 한국어 프로젝트 목록이었다.

| 확인한 항목 | 이번 변경과 근거 |
|---|---|
| 제목과 줄바꿈 | 화면·절 제목에 Georgia·바탕 계열, 보통 굵기와 좁은 자간이 함께 지정돼 있었다. 한글 제목은 설치된 산세리프와 700 굵기, 한글 본문은 어절 기준 줄바꿈을 사용한다. 이전 브라우저가 실제 선택한 글꼴은 미확인이다. |
| 목록과 예제 | 내 프로젝트에 실제 제목·창작 문구·저장 시각·열기와 세 단계 상태를 표시한다. 프로젝트가 있으면 예제를 작은 보조 행으로, 없으면 예제 지도를 포함해 보여 준다. 현재 저장된 지형만 작은 미리보기에 사용한다. |
| 장소 수 | 이전 수치는 지도 소유 레코드와 배치 레코드 ID를 합산해 좌표 유무를 구분하지 않았다. 지금은 시나리오 선언 수, 시나리오와 지도의 고유 장소 수, 실제 지형 범위 안에 점이나 면 좌표가 있는 고유 장소 수를 나눈다. 지형이 없는 경우 배치 수를 생략한다. 저장된 설정에 지형이 누락된 경우 별도 상태를 표시한다. |
| 저장과 출처 | 단계 상태는 기존 승인·출처 판정에서 읽는다. 원본 변경 뒤에도 저장된 지형은 표시한다. 새 검증을 만들거나 승인하지 않는다. IndexedDB v2 마이그레이션은 직전본 보관소를 추가하며 프로젝트를 재생성하지 않는다. 채택 전 지도 작업본은 별도 저장소에 있을 수 있다. |
| 작업 화면 | 긴 소재 원문 입력, 선택한 제안의 표시, 장문 읽기 폭, 시나리오 방문 조건과 두 줄 한글 제목, 지도 명칭 충돌 회피, 사전 관계 이름·기술 정보 접기, 복원 비교 폭과 운영 수치 설명을 다듬었다. 운영의 응답·실패·거절 합계에는 실제와 모의 요청이 포함된다. 세부 표에서 나누어 본다. |
| 출력과 비용 | 새 폰트 자산 0 B. 초기 JS 합계 596.94 kB / gzip 186.14 kB(직전 약 185 kB). 공개 지도 SVG 142,787 B. 동일한 시드 42 예제 JSON에서 렌더했고 3,456개 지형 셀과 JSON 해시를 유지했다. 실제 모델 요청과 비용은 0이다. |

시드 37 테스트 지도의 SVG는 요소 217개, 110,182 B였다. 합성 그래프 96노드·115연결은 SVG 요소 1,389개, 95,689 B였고 예열 후 서버 렌더 7회 중앙값은 22.2ms였다. 이 측정은 브라우저 프레임 시간을 포함하지 않는다.

이전 진단용 프롤로그 사본은 리비전 10, 시나리오 장소 6곳이며 저장된 world가 없다. 사본의 SHA-256은 확인 전후 `173826c926b07a383458c0dcedd5344b12f0c8edf77c0c661de8d2ac666ff0eb`였다. 현재 **잊혀진 달**의 최신 정본·지도 작업본은 확인되지 않았다. 소유자의 실제 IndexedDB를 열지 않았다.

격리 브라우저 접근 호스트를 사용할 수 없어 이번 실행에서 캡처한 화면은 0장이다. 1920×1080, 1440×900, 1280×720, 960×720의 배치·키보드 이동·그래프/지도 표지 충돌은 [소유자 검수표](PHASE_5E_ACCEPTANCE.md)에 남겼다.

### 보존 범위와 운영 수치

동일 프로젝트에서 창을 전환하면 방문한 편집기, 선택, 초안과 뷰포트가 유지된다. 다른 프로젝트로 떠나기 전에는 구조화 양식을 저장해야 한다. 저장형 자유 입력 초안에는 기존 브라우저별 보관 계약을 적용한다. 한국어·영어 선택은 표시 설정이다. 정본 v1, IndexedDB v2, 승인·검증 지문, 원자적 복원과 토큰 비교, 공급자 보안 경계를 그대로 사용한다.

운영 집계는 **현재 프로젝트의 고유 AgentRun ID**와 **이 브라우저·DB·프로젝트의 최근 소재 영수증 50건**을 사용한다. 검증 보고서는 실행 ID에 연결해 중복 호출을 더하지 않는다. 수신 후 구조 검증에서 거절된 응답은 수신과 출력 거절 양쪽에 기록될 수 있다. 사용자 수락·거절도 영수증 보관 한도에 포함된다. 전송 확인이 없는 기록, 차단된 브라우저 저장소와 서비스가 제공하지 않는 배포 버전은 미확인이다. 최신 실행과 소재 영수증은 출처별 다섯 건을 표시한다. 오래된 이력과 전체 서버 통계의 합계를 추정하지 않는다.

### 시연 데이터와 5F 인계

**Salt Census**는 공개 합성 예제다. 두 장, 장면 7개, 연결 7개, 퀘스트 2개, 결말 2개, 시나리오에 배치된 장소를 포함한 지도 장소 7곳과 경로 6개를 담았다. 기록된 결정론적 검사 도구 6개가 통과했고 상태 10개에서 결말 경로 2개를 찾았다. 새 사본에서는 이 검사를 과거 이력으로 표시한다. 편집 후 JSON 재가져오기와 독립 사본 두 개를 자동 검증했다. [예제 JSON](../frontend/public/examples/salt-census.json) · [실제 데이터에서 내보낸 SVG](../frontend/public/examples/salt-census.svg)

격리된 브라우저 호스트 연결이 실패했다. 기존 Chrome 창 선택은 개인 로그인 화면이 노출될 수 있어 자동 승인 검토가 거절했다. 격리용 Vite 서버는 종료했다. 이번 실행의 증거는 로컬 API, jsdom, 모의 IndexedDB, SVG 서버 렌더와 빌드다. 실제 화면 캡처와 기기별 로딩·프레임 시간은 미측정이다. 소유자 프로젝트와 브라우저 DB를 사용하지 않았다. 실제 ChatKHU·OpenAI 요청 및 유료 크레딧 사용은 모두 0이다.

5F에서는 한영 줄바꿈, 키보드와 지도·그래프의 실제 조작을 검수하고, 발견한 결함을 수정한 뒤 소유자 검토와 원격 CI·PR 근거를 남긴다. [소유자 검수 절차](PHASE_5E_ACCEPTANCE.md)
