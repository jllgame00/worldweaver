# Phase 3 검토 보고서 · Procedural World Atlas

**소유자 검토 준비 PASS.** 승인된 시나리오에서 절차적 지도를 생성하고, 실제 이동로를 편집·검사하고, 프로젝트에 승인·저장한 뒤 다시 여는 흐름을 구현했다. 지도 생성, 복구, 검증의 실모델 호출과 크레딧 사용은 0이다. 소유자의 실제 저장 프로젝트와 브라우저 조작 검증은 대기 중이다.

## 구현과 계약

| 기능 | 검토할 동작 |
|---|---|
| 지도 생성 | 소형·표준 대륙 또는 섬, 고도·해안·산지·구릉·평야·계곡·숲·기후, 내륙 호수, 하향 배수 하천과 폐쇄 분지. 같은 입력·버전·시드로 재생 가능 |
| 지역·여정 | 연결된 지리 지역과 별도의 정치 영토, 선택적 세력 영향. 지형 비용을 반영하는 도로·샛길, 교량·산길, 항구와 해로, 지하 터널. 수로·수로교는 자연 하천·플레이어 여정과 별도로 검증 |
| 시나리오와 장소 | 시나리오 장소의 원래 ID를 참조하는 배치, 지하 층과 대표 이동점·면, 현재 승인 여부와 원본 버전 검사. 장면에서 장소로 이동하고 장소에서 연결된 장·장면·퀘스트와 참여 인물을 확인 |
| 편집과 검토 | 마우스/키보드 탐색, 확대·이동·선택, 레이어, 축척·범례, 검색 목록. 명칭·설명·좌표·유형·영향 세력, 장소·경로 추가/삭제, 잠금, 재배치, 지리 조건, 되돌리기·다시 실행 |
| 복구와 저장 | 차단 오류를 가진 작업본도 독립 저장. 원본 변경 시 재조정, 편집 후 경로 재계산과 무료 재검증, 명시적 초안 채택 또는 승인. 기존 승인본과 다른 탭의 수정 보호 |
| 상호운용 | Project v1 Draft 4 확장, 기존 IndexedDB 그대로 사용. JSON 전체 백업·가져오기, 지리 Markdown, 범례와 축척을 포함한 SVG. 이전 프로젝트 열기에 별도 변환 불필요 |

시드 기반 잡음과 연결 성장을 선택해 육지가 섬 프리셋을 제외하고 한 주 대륙을 이루게 했다. 셀 정수 고도를 사용해 하천 흐름을 검사하고, 지역·면의 윤곽은 렌더링할 때 추출한다. 경로는 지형 비용으로 탐색하므로 편집 후에도 같은 규칙으로 재계산할 수 있다. React와 브라우저 SVG를 사용해 런타임 패키지·라이선스·잠금파일 추가가 없다. 물리적 관계가 모호하면 소유자가 지리 요구와 근거를 지정한다. [생성·편집 규약과 단위](WORLD_GENERATION.md) · [데이터 스키마](DATA_SCHEMA.md)

## 소유자 확인 절차

1. 저장소에서 `.\scripts\start-dev.ps1`을 실행한다. 처음 설치하는 환경이면 `.\scripts\setup.ps1`을 먼저 실행한다. 기존 프로필과 `http://127.0.0.1:5173`을 사용한다.
2. **Projects → Open**에서 **잊혀진 달**을 열고 **Export project JSON**으로 기존 상태를 백업한다. **천 명의 증인**과 시나리오가 현재 버전에서 승인되었는지 확인한다. 시나리오가 제안 상태라면 기존 제안을 검토·채택·검증하고 승인한다.
3. **World Atlas → Geography requirements**에서 실제 장소 ID에 연결된 요구와 여정을 검토한다. 묵정·공동묘·숲·마을·옛 도읍·저수조 사이의 관계는 승인된 프로젝트에 기록된 것만 기준으로 삼는다.
4. 기본 대륙, 시드 `42`에서 **Generate continent**를 누른다. **Layers**로 지형, 하천, 정치 지역, 교통과 시나리오 여정을 살핀다. 지도에서 장소를 선택하고 **Zoom to selection**을 확인한다.
5. 검사기의 장면 이름을 클릭하고 **Show location on atlas**로 돌아온다. 잠기지 않은 장소를 선택해 **Column / Row → Save location**으로 인접 육지에 옮기고 경로를 확인한다. **Revalidate world**로 지적 사항을 연다. 필요하면 **Undo atlas edit** 또는 조건 수정·경로 재계산으로 복구한다.
6. 차단 오류를 해소하고 **Approve world**를 누른다. **Export saved project JSON**, **Export SVG**, **Export atlas Markdown**을 저장한다. 같은 주소에서 새로고침·재열기 후 **Approved world**, 이동한 장소와 경로를 확인한다. 실행 터미널에서 Ctrl+C로 종료한다.

## 검증 범위와 다음 단계

소유자가 실제 ChatKHU 시나리오 그래프를 확인했다는 이력이 있다. 이번 작업에 소유자의 내보낸 파일은 제공되지 않았으며, 소유자 브라우저 저장소를 읽지 않았다. 실제 시나리오 최종 승인과 JSON 백업 여부는 위 절차에서 확인해야 한다. Chromium 실행은 `spawn EPERM`으로 차단됐고 별도 브라우저 호스트도 사용할 수 없었다. PNG는 SVG 출력 증거이며 실제 브라우저의 화면 캡처는 없다. 실행한 검증 서버는 종료했다.

캠페인은 두 격자 크기와 정해진 시드 범위에 대한 관측이다. 제한된 배치 탐색에서 어려운 입력은 소유자가 수정할 수 있는 실패 제안으로 남는다. 배수·생태·정치·층별 거리는 설계용 근사치다. 수로의 수압, 배의 흘수, 계절별 유량이나 실제 여행 시간을 검증하지 않는다. 프로젝트 JSON은 채택한 정본 백업이다. 분리된 작업본과 화면 설정은 같은 브라우저 주소·프로필에 의존한다.

Git HEAD는 시작과 같다. 추적 파일 18개를 수정하고 파일 36개를 추가했다. 변경은 프런트엔드 Atlas 엔진·렌더러·검사기·복구 저장소·시나리오 이동, 공유 정본과 Python 참조 검사, 테스트·캠페인·프로젝트 문서에 있다. 커밋·푸시·배포는 수행하지 않았다. Phase 4에서 사용할 장소·여정 ID, 출처 버전, 물리 경로, 결정적 검사 영수증이 준비됐다. 실제 소유자 지도의 지리적 의미와 조작성 승인이 다음 단계의 검토 조건이다.
