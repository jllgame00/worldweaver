# WORLDWEAVER 편집 작업대

목록에서는 최근 설계와 백업을 먼저 찾고, 편집 중에는 프로젝트 이름과 저장 상태를 고정 머리글에서 확인한다. 데스크톱은 세로 탐색 레일을 쓰고, 좁은 창에서는 머리글 버튼으로 탐색을 펼친다.

한글 UI와 창작 제목에는 로컬 한글 산세리프를 쓴다. 영어 창작 제목에 사용하는 Georgia도 한글 글리프는 같은 산세리프로 이어진다. 흑연색 바탕과 따뜻한 금속색 포커스, 지도에 한정한 양피지 바탕을 사용한다. 아이콘에는 보이는 이름이나 접근성 이름을 붙인다. 상태는 문구로도 표시한다.

그래프에서는 장·분기 배치, 작은 전체도와 실제 검사 경로를 우선한다. 지도 장식과 명칭 배치는 렌더러에서 처리하며 좌표와 경로를 저장하지 않는다. 소재와 스토리 후보는 원문을 보존한 채 비교한다. 운영 창은 로컬 기록의 출처·집계 범위를 표시한다. 정본·저장·승인 계약은 기존 편집기와 저장소가 처리한다.

| 요소 | 구현 기준 |
|---|---|
| 화면과 글자 | 바탕 `#1a1c1c`, 패널 `#222525`, 기본 글자 `#f0e7da`, 보조 글자 `#bfb2a0`. 로컬 Pretendard, Apple SD Gothic Neo, 맑은 고딕, Noto Sans CJK KR, Segoe UI, 시스템 기본 순서다. 폰트 파일과 CDN 요청은 추가하지 않는다. |
| 선택과 상태 | 황동색 `#d8b77d`, 포커스 `2px solid #f4cb87`, 통과 `#b2c7a5`, 오류 `#f0a89c`. 현재 위치, 오류, 실제 승인과 저장에는 글자나 접근성 상태를 함께 제공한다. |
| 컨트롤 | 기본 간격 0.5rem, 반경 4px. 버튼·선택·텍스트 필드·탭·비교 표·알림이 공통 CSS를 사용한다. 요약과 세부 정보는 키보드로 열리는 details/summary를 사용한다. 그림자는 떠 있는 메뉴·복원 검토에 제한한다. 기본 전환 120ms, 모션 감소 설정에서는 0ms. |
| 작업 면적 | 기본 레일 12.5rem, 1150px 이하 10.5rem, 1024px 이하 접이식. 지도와 목록은 1200px부터 좌우 배치한다. 그래프는 상세 편집을 접어 넓힐 수 있고 좁은 창에서 세로로 쌓인다. 560px 이하에서 주요 버튼 높이는 최소 42px이다. |
| 그래픽 | 내부 SVG 선 아이콘과 텍스트를 함께 사용한다. 그래프의 진행·선택·참조·이동은 선 종류로 구별한다. 지도 기호와 범례는 켜진 레이어와 실제 데이터에서 만든다. |

구현 기준은 `frontend/src/styles.css`와 도구별 CSS에 있다. 배치별 실제 한글 줄바꿈, 모니터 배율과 브라우저 포커스는 [시각 검수표](PHASE_5E_ACCEPTANCE.md)에서 확인한다.

토큰의 sRGB 상대휘도로 계산하면 패널 배경에 대한 기본 글자는 12.61:1, 보조 글자는 7.42:1, 황동색은 8.08:1이다. 지도 위 글자와 겹친 표지의 판독성은 화면 검수 대상이다.

### 한글 조판과 보관함

화면 제목·절 제목·프로젝트 이름은 각각 `--type-page`, `--type-section`, `--type-project`를 사용한다. 세 제목의 굵기는 700, 줄높이는 1.32~1.45다. 본문·입력 레이블·보조 정보·기술 값에는 `--type-body`, `--type-label`, `--type-meta`, `--type-technical`을 사용한다. 한글 문구는 어절 단위로 줄을 바꾸되 폭을 넘는 긴 이름과 ID에는 줄바꿈을 허용한다. 그래프와 지도에서 줄인 이름은 상세 편집기와 색인에서 전문을 확인한다.

저장된 프로젝트 한 행에는 제목·열기, 두 줄까지의 실제 창작 문구, 저장 시각, 스토리·시나리오·지도 상태와 장소 수를 배치한다. 직사각형 지형이 있으면 저장된 셀에서 작은 지형도를 그린다. 지형이 없으면 문서 표식을 쓴다. 첫 방문에는 공개 예제 지도를, 재방문에는 보관함 아래에 예제 이름과 사본 만들기를 표시한다.
